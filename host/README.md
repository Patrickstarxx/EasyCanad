# EasyCanad 控制台

这是与固件 v6 配套的 Windows / Android 网页上位机。页面包含设备状态、全部控制参数、机型档案和日志曲线。Windows 使用浏览器 Web Serial 连接 Nano；Android 可先安装网页并使用模拟设备，USB 串口连接仍需在实际手机、转接器和 Nano 上验证。

## 启动

需要 Node.js 24 或更高版本。在 `host/web` 目录运行：

```powershell
npm ci
npm run dev
```

打开终端给出的本机地址，点击“使用模拟设备”即可检查各页面和调参流程。连接 Nano 时，先按 [固件说明](../FIRMWARE.md) 在地面接线、进入 GROUND，再点击“连接 USB 串口”并选择对应端口。串口使用 500000 baud。控制台不会在连接、应用或保存后自动进入 RUN；只有明确点击“手动进入 RUN”时才发送 `run`。设备自身还会检查 D5 跳线和遥控输入。

`npm test` 检查协议兼容、配置顺序、机型迁移和模拟设备操作。`npm run build` 生成可离线缓存的静态 PWA 到 `host/web/dist`；`npm run preview` 可以在本机查看构建版本。安装到桌面或手机时，需要从支持安装的安全页面提供这些静态文件。发布可直接使用 CI 中的 `easycanad-host-pwa` 构建产物。

## 数据与使用边界

- 固件 v4 / v5 / v6 的配置与日志可以读取；v6 的新控制律参数只能写入 v6 固件。应用参数会逐项发送并回读，保存会写入 EEPROM。写入中途失败时，页面显示已回读的设备状态。
- 机型档案 v2 保存完整控制参数，浏览器本地存储可供当前浏览器使用；建议导出 JSON 做备份。旧版 `profiles/*.json` 的 v1 机型文件可导入并转换。
- 日志采集只在页面保持打开且串口连接时工作。原始 E/C/R/D 行保留在当前页面内存中，断开连接后仍可导出本次记录；开始新记录或刷新页面会替换这份记录。长时采集仍需独立记录方案验证。
- 模拟设备的数据是界面演示值，不代表实际控制算法或真实飞行数据；模拟记录不提供原始固件日志导出。
- 当前没有 Nano、台架或 Android 实物的验证结果。固件编译、模拟协议测试、页面构建和浏览器操作不能替代风标方向、舵机机械行程、失控保护及 USB 实机验证。

## 源码

- `web/src/transport/`：浏览器串口与模拟设备。
- `web/src/protocol/`：固件记录编解码、控制参数、写入顺序、机型文件和日志。
- `web/src/main.ts`：四个页面及交互。
- `web/scripts/generate-sw.mjs`：构建时生成静态资源离线缓存。
