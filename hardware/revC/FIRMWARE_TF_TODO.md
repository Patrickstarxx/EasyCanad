# Rev C 外接 TF 模块：后续固件工作

本轮只做硬件，现有固件不会因插卡自动记录。控制算法、串口协议、EEPROM 配置均未修改。

| 功能 | Nano 引脚 | Rev C 约定 |
|---|---|---|
| TF 片选 | D10 | 5V，经 R14 33Ω 到 J8.3 |
| MOSI | D11 | 5V，经 R15 33Ω 到 J8.5 |
| MISO | D12 | J8.9，外接模块须输出 5V |
| SPI 时钟 | D13 | 5V，经 R16 33Ω 到 J8.7 |
| 可选插卡检测 | D6 | J8.10，R13 上拉；Pololu2587 插卡为高、无卡接地 |

1. D10 先配置输出并置高，再初始化 SPI；SPI 模式 0，初始化不超过 400kHz，工作时钟先以 1MHz 联调。
2. 使用带 3.3V 稳压、SPI 电平转换及 MISO 转 5V 的模块；参考 Pololu2587。载板没有 3.3V 稳压/电平转换，不能接裸卡。
3. D6 极性以所选模块为准。本版默认 Pololu2587 的**高有效**插卡检测，与早期无源卡座的低有效约定不同。需要去抖、允许关闭检测；模块未接检测线时不能仅靠 D6 认定插卡成功，还要检查初始化结果。
4. D13 与 SuperNano 板载 RGB 数据引脚物理共用。SPI 使用期间禁止运行 NeoPixel 驱动和长时间关中断更新 RGB；SPI 脉冲仍可能引起灯响应，需测耗电和波形。
5. ATmega328P SRAM 为 2KB，评估 SD/FAT 常见 512B 扇区缓存、静态数据和最大栈；避免动态字符串、多扇区缓存占满内存。
6. **写卡最坏延迟必须与控制时限隔离。** 不在每个控制周期直接同步 `println`/`flush`；使用有界状态机、预分配及允许丢日志的策略。若库无法满足时限，改用独立日志处理器，不以平均写入速度代替最坏延迟证明。
7. 保留日志版本、时间戳、配置快照、开机事件与丢帧计数。满卡、拔卡、初始化失败、写错误均不得停止控制主循环。
8. 先限定已测试的 SDHC/FAT32 卡，不默认支持 SDXC/exFAT。C1 只作总线去耦，没有掉电保持能力，不能保证断电时 FAT 完整。
9. 在台架记录控制周期最大值、舵机脉冲抖动、PWM 捕获丢失、SRAM 峰值、最坏写入延迟和断电恢复结果。

A0、D2、D3、D4、D5、D7、D9 的原分配不变。J3 同时作为供电入口不要求固件更改；J4/J5 中心针不连接电源。
