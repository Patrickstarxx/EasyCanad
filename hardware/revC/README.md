# EasyCanad Rev C：紧凑型 SuperNano 插接载板

本版落实追加要求：Nano 排针直接插接、PWM 按组排列、开关跳线集中、移除载板全部 3.3V 稳压/电平转换、由俯仰 PWM 接口取 5V 电源、中文原理图和系统电路示意图。仅修改硬件与说明，未修改固件。

## 交付入口

- `EasyCanad SuperNano TF RevC/EasyCanad SuperNano TF RevC.eprj3`：嘉立创 EDA 专业版工程，须保留整个同名目录。
- `exports/EasyCanad_RevC_Gerber.zip`：本版生产文件；不要混用旧 Rev B 的 Gerber。
- `exports/BOM_assembly.csv`：装配采购清单，含板外 Nano、排针、跳帽和 TF 模块。
- `exports/schematics/`：四页原理图；`exports/pcb_routed.png` / `pcb_bottom.png`：从实际 Gerber 渲染的正反面预览。
- `exports/系统电路示意图.svg` / `.png`：中文系统组成、供电和接口示意图。
- `exports/nano_socket_1to1.svg`：Nano 插座 1:1 孔位图；打印选择 100%，核对 20mm 校验线。
- `nano_socket_geometry.json`：厂家原始 PCB/STEP 的孔位提取与交叉检查。
- `evidence/validation_report.json`：针脚、插座坐标、制造文件及 EDA 规则检查结果。
- `FIRMWARE_TF_TODO.md`：后续日志固件要求，本轮未实现写卡。

PCB 为 **45.72 × 40.64mm，双层**，比早期 80.01 × 64.77mm 版本面积减少约 64%。建议 FR-4、1.6mm、1oz 铜。采用 0805、SOP-8 和 2.54mm 通孔接口，适合先焊贴片、再焊插座和连接器。两处 Φ3.2mm 安装孔位于板左上和右下侧，安装螺钉头部外径不超过 6mm。

原理图为 38 个板上元件、114 个器件针脚；实际复核结果见检查报告。没有实物上电记录，生产文件检查不能代替台架测试。

## Nano 插接孔位

载板焊 **2 个 1×9 和 1 个 1×5 的同高度直立排母**，Nano 在内侧通孔焊朝下的公排针，正面朝上、USB-C 朝载板上沿。厂家模块通孔名义直径为 0.9144mm，公排针的焊接尾针须先与实物孔试配，三排同时对齐后再焊接。推荐统一使用 8.5mm 排母，并保证两块 PCB 之间至少 8.5mm 净间隔；模块下面只布置高度不超过 2mm 的 0805 阻容，电解电容不在模块下面。

孔位来自[厂家论坛及资料目录](https://chat.nologo.tech/d/115)提供的 `supermini nano328-WX.PcbDoc` 与 `3D_supermini nano328.step`，使用内侧通孔，排除板边半孔。两份文件的 23 个孔中心最大差异约 0.000051mm。

| 关系 | 尺寸 |
|---|---|
| 每排针距 | 2.54mm |
| 两侧 9 针排中心线间距 | **15.46mm** |
| 9 针排首末跨度 | 20.32mm |
| 尾部 5 针排相对 D8/A0 基线 | 向模块尾部偏移 **0.289804mm** |
| 尾排 D9 相对左侧 D0/D8 排 | 向右 2.65mm |

孔位图按“USB 朝上、D0 为原点、向右/向下为正”定义：左排 `(0,0…20.32)`，右排 `(15.46,0…20.32)`，尾排 `(2.65…12.81,20.609804)`，每排步进 2.54mm。不能吸附为 15.24mm 排距或把尾排移到 D8/A0 基线上。三组排母相对位置已锁定，后续编辑应整体移动。

先用 1:1 孔位图校核手头模块。焊接时将三个排母同时套在 Nano 公排针上定位，先点焊、检查平齐，再完成焊接；保留所有 23 个插接位置。

| 载板插座针号 | 对应 Nano 丝印 |
|---|---|
| JN1，1～9 | D0、D1、D2、D3、D4、D5、D6、D7、D8 |
| JN2，1～9 | 5V、GND、VIN、A5、A4、A3、A2、A1、A0 |
| JN3，1～5 | D9、D10、D11、D12、D13 |

VIN、D0/D1、D8、A1～A5 在载板不引出功能网络。VIN 保持电气悬空，模块由 **5V 脚**供电。

## 分区与接口

以顶视图、USB 朝上为准：左上为 PWM 输入组，左下为单舵机输出组；上方中央为 Nano；右上为风标，右侧中部为按钮/跳线，右下为 TF 模块接口；下方中央为供电保护和总线电容。

| 接口 | 功能与针脚 |
|---|---|
| **J3 俯仰/供电** | **1 GND，2 稳压 5V 输入，3 俯仰 PWM → D2** |
| J4 模式输入 | 1 GND，**2 NC**，3 模式 PWM → D3 |
| J5 油门采样 | 1 GND，**2 NC**，3 油门 PWM → D7 |
| J2 舵机输出 | 1 GND，2 保护后 5V 总线，3 PWM（D9 经 R8） |
| J6 霍尔风标 | 1 GND，2 逻辑 5V，3 模拟 0～5V → A0；对应 0～360° |
| SW1 / J7 标定 | SW1 板载按钮；J7.1 D4、J7.2 GND，接外置常开按钮 |
| JP1 电源跳线 | 1 保护后 5V 总线，2 逻辑 5V；运行短接，接带电 USB 前拔掉 |
| JP2 地面配置 | 1 D5，2 GND；需要进入 GROUND 时在上电前短接 |

三个 PWM 输入方向相同，舵机输出也沿用相同的 GND/电源/信号方向。J4/J5 中心针在 PCB 上悬空，避免其他通道的红线绕过反接保护形成第二条供电路径。按方形焊盘识别 1 脚，不按照片左右猜针号。

电调 BEC 以正常方式给接收机供电，再由接收机的**俯仰三芯线接 J3，为整板供电**。电调油门信号仍接接收机，J5 仅用 Y 线采样油门，不接管电调。所有信号地共地；只使用一个 5V BEC。

J3、接收机供电总线与线束必须承担舵机、Nano、风标及 TF 模块的总电流。供电触点选择额定至少 3A 的 2.54mm 插接件，电源线以 22AWG/约 0.35mm² 起步，按实际堵转电流、压降及温升确认。5V 总线不接受 6V/HV BEC 或电池原始电压。Q1 保护载板供电通路，不能代替接收机自身的极性保护。

## 电路说明

- Q1 AO4407A 与 R1 构成输入反接保护；舵机由保护后的总线直接供电，不经过 Nano 板载稳压器。
- C1 为 470µF/16V 总线去耦，注意极性；主供电与舵机支路约 1.52mm，主要地回流约 2.03mm，芯片引脚处有必要收窄。
- R2/R3/R4 为各路 PWM 的 1kΩ 串阻，R5/R6/R7 为 100kΩ 下拉；本版直接输入 Nano，不装接收机电平转换芯片。按 5V PWM 设计，输入高电平须满足 ATmega328P 数据手册门限（至少 0.6×VCC），不能仅凭“3.3V 接收机”名称认定兼容。
- D9 经 R8 1kΩ 输出舵机脉冲，R9 100kΩ 提供下拉。没有主控故障硬件旁路。
- 风标经过 R10 1kΩ/C5 100nF 滤波送 A0，截止约 1.59kHz；C6 对传感器供电去耦。
- R11/R12/R13 为标定、地面配置及可选插卡检测的 10kΩ 上拉；C2/C3/C4 为逻辑和 TF 接口去耦。

## USB 与外部电源

断电后拔掉 JP1，再插 USB-C。需要接收机和舵机通电时，BEC 可继续通过接收机/J3 给总线供电，**JP1 仍须保持断开**；两侧共地。退出调试时先断 USB 和 BEC，再装回 JP1。

不假定这款 Nano 内部具有自动 USB 防回灌隔离，也不通过 USB 给舵机供电。USB 单独供电时还要核对 Nano 与 TF 模块的写卡峰值是否超出 USB 供电预算。

## 5V TF 模块接口

**载板已移除全部 3.3V 稳压和电平转换电路。Nano 的 5V 供电不会自动把 SPI 降为 3.3V。** J8 必须连接自带 3.3V 稳压及完整 SPI 电平转换的外接模块，包含 MISO 返回 5V；禁止接裸卡或无源卡座。

参考器件为 [Pololu 2587](https://www.pololu.com/product/2587)，厂家明确说明 DO/MISO 已转换为 5V。其他模块须满足同等电气接口，不能仅凭标有“5V 电源”认定所有信号兼容。

| J8 针号 | 本板信号 | Pololu 2587 对应端 |
|---|---|---|
| 1 | 逻辑 5V | VDD |
| 2、4、6、8 | GND | GND |
| 3 | CS，5V | CS |
| 5 | MOSI，5V | DI |
| 7 | SCK，5V | SCLK |
| 9 | MISO，模块输出 5V | DO |
| 10 | 可选插卡检测 → D6 | CD，插卡为高；可不接 |

Pololu 的 3V3 输出不接载板，EN 保持模块默认上拉使能。J8 的 2×5 针序不是模块原生针序，按信号名称逐根接短线，建议不超过 50mm。R14/R15/R16 各 33Ω，仅作 CS/MOSI/SCK 串联阻尼；R17 保持复位期间片选为高，R18 保持时钟为低。

模块和卡不从 Nano GPIO 取电。外部模块保留厂家要求的近端去耦；无有效日志固件时插卡不会自动记录。

## 首次台架核对

先焊低矮贴片件，再装 C1、排母和连接器。确认 Q1 方向、C1 极性、JP1/JP2 作用、J3 供电方向及 TF 模块类型。

1. 断开动力并固定机构，未插模块时测短路与供电极性，用限流稳压 5V 从 J3 上电。
2. 检查保护后总线和 JP1 两侧；验证 USB/外电分开供电时的隔离，再插 Nano。
3. 接收机三路 PWM、风标零位/满量程及 360° 接缝逐一核对，使用现有默认 `law_mode 0` 检查舵机方向、限位与失控行为。
4. 测舵机全行程/堵转瞬态下的电源压降、连接器温升、接收机状态和 Nano 复位情况。
5. 后续 TF 固件以初始化 400kHz、工作 1MHz 起步，测波形、电流、最坏写入延迟及控制连续性。

没有采购、下单或合并现有固件分支。本版取代早期载板方案，固件引脚 A0、D2/D3/D4/D5/D7/D9 保持原分配。
