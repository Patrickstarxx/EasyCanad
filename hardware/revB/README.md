# EasyCanad 硬件 Rev B — SuperNano + 外接 TF

> 最新硬件为 [Rev C 紧凑插接载板](../revC/README.md)，包含厂家原始孔位、接口分组、俯仰接口供电和中文说明。本目录保留早期设计，请勿混用两版生产文件。

本版对应 2026-10-25 确认的需求：NOLOGO SuperMini Nano328P、5V 电调 BEC、一个 5V 9g 舵机、0～5V/360° 模拟霍尔风标、三路独立 PWM 输入、外接 TF 卡接口。仅修改硬件和说明，固件未改动。

## 电路与板子

PCB 外形 80.01 × 64.77mm，双层，建议 FR-4、1.6mm、1oz 铜、普通绿油白字。提供两个 Φ3.2mm 安装孔。0805 电阻/陶瓷电容、SOIC/SOP 逻辑芯片、SOT-223 稳压器和 2.54mm 通孔连接器适合手工焊接。

- Q1 用 P 沟道 MOSFET 处理 J1 输入反接；5V 直接进入受保护总线，**不经过 Nano 的 VIN 或板载稳压器给舵机供电**。
- 舵机和接收机使用 `+5V_BUS`。JP1 将该总线接到 `+5V_LOGIC`，供 Nano 的 5V 脚、风标、逻辑芯片及 TF 稳压器。
- C1 为 470µF/16V 的总线去耦；舵机供电主干约 1.52mm、主回流约 2.03mm，MOSFET 引脚和连接器处有必要的收窄。它不提供掉电保存能力。
- U4 的前三路将 3.3V 或 5V 接收机 PWM 转成 5V，前端串联 1kΩ、下拉 100kΩ；俯仰/模式/油门仍分别送 D2/D3/D7。
- 风标经过 1kΩ + 100nF 送 A0，滤波截止约 1.59kHz。传感器仍需按现有固件校准。
- U2 AP7361C-33E-13 提供独立 3.3V，使用陶瓷输入/输出电容及 GND 散热铜。U3 将 CS/MOSI/SCK 降为 3.3V，U4 第四路将 MISO 转为 5V。
- 本版没有主控故障硬件旁路，也没有 IMU、空速计、备用电源或已运行的 TF 日志功能。

连接器是通用 2.54mm 排针/排母。原理图检查保留一项 `ATTRMATCHCODE` 提示，涉及 13 个通用连接器：器件显示属性与库的供应商条目不完全匹配。原生 BOM 仍保留这些库索引编号，仅作为库来源；`BOM_assembly.csv` 对这些通用件不指定采购 SKU，应按针数、间距、直插方向和封装选择。此提示不涉及网络或 PCB 间距，IC、电阻、电容保留具体料号。

## SuperNano 采用线束连接

**JN1/JN2/JN3 是三组短线束接口，不是可直接插入 SuperNano 的机械插座。** SuperNano 的三排孔位与标准 Nano 不同，厂家公开尺寸图未完整给出所有排间孔中心距离。本版避免臆测孔距：将模块单独固定，依照模块丝印逐根接线，保持 USB-C 可插拔。建议线束不超过 50mm，SPI 线尤其要短，并伴随地线。

针号按 PCB 方形焊盘为 1，后续以封装标号递增。不要按照片左右方向猜针号。

| 接口 | 针号 → SuperNano 丝印 |
|---|---|
| JN1，1×9 | 1 D0 不接；2 D1 不接；3 D2；4 D3；5 D4；6 D5；7 D6；8 D7；9 D8 不接 |
| JN2，1×9 | 1 **5V**；2 **GND**；3 VIN 不接；4 A5 不接；5 A4 不接；6 A3 不接；7 A2 不接；8 A1 不接；9 A0 |
| JN3，1×5 | 1 D9；2 D10；3 D11；4 D12；5 D13 |

“不接”针脚留作机械位置识别，板上没有功能网络，不连接模块也可以。模块的 VIN 保持悬空。D0/D1 由模块 USB 串口使用，不从载板外接。

## 对外接线

| 接口 | 功能 | 针脚定义 |
|---|---|---|
| J1，1×2 | 5V BEC 输入 | 1 +5V；2 GND |
| J2，1×3 | 单个鸭翼舵机 | 1 GND；2 +5V_BUS；3 舵机信号（D9 经 R8） |
| J3，1×3 | 接收机俯仰 | 1 GND；2 +5V_BUS；3 PWM → D2 |
| J4，1×3 | 接收机模式 | 1 GND；2 +5V_BUS；3 PWM → D3 |
| J5，1×3 | 接收机油门采样 | 1 GND；2 +5V_BUS；3 PWM → D7 |
| J6，1×3 | 模拟风标 | 1 GND；2 +5V_LOGIC；3 0～5V 模拟信号 → A0 |
| SW1 / J7 | 零位标定 | SW1 为板载按钮；J7.1 D4，J7.2 GND，可接外置常开按钮 |
| JP2，1×2 | 地面配置跳线 | 1 D5；2 GND；需要进入 GROUND 时在上电前短接 |
| JP1，1×2 | 逻辑电源连接 | 1 +5V_BUS；2 +5V_LOGIC；运行装跳帽，接带电 USB 前拔掉 |

J5 只采样油门，不代替电调的油门输入。接收机油门信号可用 Y 线分别送 J5 和电调，电调信号地也要共地。

**只保留一个 BEC 供电入口。** 本版约定电调 BEC 的 5V/GND 接 J1，接收机由载板总线供电。如果电调三芯插头也接接收机，应将其中红色 BEC 电源线退出插壳并绝缘，保留信号与地，避免绕过 Q1 形成第二条供电路径。多条接收机 PWM 线束可只保留一条红线，其余保留信号和地。

只输入稳压 5V；不接 6V/HV BEC，也不接电池原始电压。BEC 容量要覆盖舵机堵转、接收机、模块、风标及写卡峰值。本版以连续约 2A、瞬时约 3A 的整机供电需求作为台架选型起点，最终以所用舵机、BEC 及线束的实测结果确定，不以“9g”推断堵转电流。

## USB 调试供电

1. 先断电，拔下 JP1。
2. 插 USB-C；Nano、风标和 TF 逻辑侧使用模块 5V 脚所提供的 USB 电源。
3. 如需接收机 PWM，BEC 可单独给 `+5V_BUS` 供电；此时 JP1 仍保持断开。地线共地，避免额外 5V 回接。
4. 结束时拔 USB、断 BEC，再装回 JP1，进入正常运行接线。

本版通过 JP1 实施电源隔离操作，不假定国产 Nano 内部具有标准 Nano 的 USB 防回灌电路。禁止 JP1 闭合时同时接带电 USB 与 BEC；也不要用 USB 给舵机供电。

## 外接 TF 卡

J8 为 2×5、2.54mm 接口，板上标出 1 脚。使用有可靠固定的短线束或同序排线；它不是通用 AVR ISP 接口。

| J8 针号 | 信号 | 去向 |
|---|---|---|
| 1 | 3.3V | TF VDD；只给无源转接板供电 |
| 2、4、6、8 | GND | TF VSS 和屏蔽/卡座外壳地 |
| 3 | CS，3.3V | TF 第 2 脚 DAT3/CS |
| 5 | MOSI，3.3V | TF 第 3 脚 CMD/DI |
| 7 | SCK，3.3V | TF 第 5 脚 CLK |
| 9 | MISO，3.3V | TF 第 7 脚 DAT0/DO |
| 10 | CARD_DETECT | 只接卡座的无源检测触点，插卡时接 GND；可不接 |

外部卡座转接板需要：TF 第 4 脚接 3.3V、第 6 脚接 GND，第 1 脚 DAT2 和第 8 脚 DAT1 各用 47kΩ 上拉到 3.3V；卡座近端放 10µF + 100nF。卡座金属壳接地。CS、CMD 和 DAT0 的上拉已在主板提供。

使用**直接引出 3.3V 卡座信号的无源 TF 转接板**。不要接带 5V 输入稳压器/分压电阻的 Arduino SD 模块，否则可能产生压降和重复电平转换。J8 不支持带电插拔；需要读卡时先停止记录并断电。

接口电源建议先按平均 ≤200mA、短时峰值 ≤500mA 的卡进行联调；1A 是 U2 器件额定值，不能等同于整板持续供电能力。需要在实际环境温度、外壳、卡和最终线束条件下测量温升与 3.3V 最低电压。

## 装配与首次检查

先焊电源和低矮贴片件，再焊排针、按钮及电解电容；确认 Q1/U3/U4 的 1 脚、U2 引脚与 GND 散热片、C1 正负极。通孔连接器采用与 BOM 封装一致的直立版本。补装 JP1、JP2 跳帽，模块和 TF 无源转接板属于板外物料。

未插模块/风标/舵机时先做短路检查，用限流 5V 上电，测 J1、总线、JP1 及 3.3V。之后按以下顺序记录实际数据：

| 项目 | 要验证的结果 |
|---|---|
| 电源 | 正接/反接行为、JP1 隔离、USB/BEC 各自供电；逻辑电压、稳压器温升 |
| 舵机负载 | 全行程及堵转瞬态下的 5V/3.3V 压降、Nano 复位和接收机状态 |
| 输入 | 三路 3.3V/5V PWM 的脉宽、断线后的低电平和超时行为 |
| 风标 | 0/中间/接近满量程读数、360° 接缝、方向、去耦和电噪声 |
| 控制 | 先使用现有 `law_mode 0`，按根目录台架方案核对方向、行程和失控保护 |
| TF | 初始 400kHz/工作 1MHz 波形、卡座近端 3.3V 峰值电流与压降；后续固件满足实时性要求后再联动测试 |
